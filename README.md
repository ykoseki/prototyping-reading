# prototyping-reading

個人の閲覧用に、パスワードで暗号化した記事アーカイブを置いているリポジトリです。
記事ページ（`01.html`〜`04.html`）は暗号化されていて、パスワードを知っている所有者だけが読めます。一覧ページ（`index.html`）は記事のタイトルとリンクだけなので、暗号化していません。

## このリポジトリについて

- このリポジトリのファイルは、すべて **Claude Code (CLI)**（Anthropic、モデル: Claude Opus 5.5）で作りました
- 作成日: 2026-11-24
- 中身: Webメディアの連載記事4本（複数ページに分かれていたもの）を、1記事1ページの縦スクロールにまとめたもの、とその一覧ページ
- 目的: 所有者が自分の別の端末から読むため（個人用）です。ほかの人と共有するためのものではありません

## Claude Code が行った処理

1. **記事の統合**：保存してあった記事HTML（p1〜pn）から、本文と関連する画像だけを取り出し、1記事1ファイルにまとめました。広告、ナビゲーション、SNSボタン、関連記事などは取り除いています。画像はHTMLの中に直接埋め込んでいます
2. **一覧ページの作成**：4記事へのリンクと、元記事へのリンクを並べたページ（index.html）を作りました
3. **暗号化**：4つの記事ページをパスワードで暗号化し、ブラウザで復号して表示するHTMLに変換しました
4. **公開**：暗号化したファイルだけをこのリポジトリに push し、GitHub Pages で配信しています

暗号化する前の記事本文のHTMLは、このリポジトリには入れていません。

## 暗号化の仕組み

| 項目 | 内容 |
|---|---|
| 鍵の作り方 | PBKDF2-HMAC-SHA256、600,000回、16バイトのsalt（サイト全体で共通） |
| 暗号化 | AES-256-GCM（ファイルごとに12バイトのランダムなIV） |
| 復号 | ブラウザ標準の Web Crypto API（外部ライブラリは使っていません） |
| パスワードの記憶 | 「この端末で記憶する」にチェックすると、パスワードそのものではなく復号用の鍵をその端末の localStorage に保存します。一覧ページの下にあるボタンで消せます |
| 検索エンジン対策 | `robots.txt` で全体をクロール禁止にし、各ページに `noindex` を付けています |

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 一覧ページ（タイトルとリンクのみ、暗号化なし） |
| `01.html`〜`04.html` | 記事（暗号化済み） |
| `robots.txt` | 検索エンジンのクロール禁止 |
| `.nojekyll` | GitHub Pages の Jekyll 処理を止める |

## 更新のしかた

更新は所有者のPCで行います。手元の平文HTMLを直したあと、暗号化をやり直して push します（暗号化スクリプトは所有者のPCにあり、このリポジトリには入れていません）。

## 著作権について

元の記事の著作権は、著者と出版社にあります。このリポジトリは所有者の個人的な閲覧のためのもので、内容は暗号化して第三者が読めないようにしています。
